# VayuSaathi — frontend

Next.js (App Router) + TypeScript + Tailwind CSS + TanStack Query.

```bash
cp .env.example .env.local   # point NEXT_PUBLIC_API_URL at your API
npm install
npm run dev                  # http://localhost:3000
npm run lint
npx next build
```

See the [root README](../README.md) for the full project, architecture and deployment.
